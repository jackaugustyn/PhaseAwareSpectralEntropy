## Responses and remaining boundary

| Review point | Revision scope |
| --- | --- |
| Exact contribution relative to low-round cryptanalysis | State the contribution as a connection between conditional word-7 identities, paired finalization effects and empirical spectrum reconstruction. Do not claim novelty for weak low-round diffusion or higher-order differences, or imply that the local rank identity derives the entire entropy gap. |
| Closest cited two-round criteria | **Partly addressed:** contribution framing is made explicit, but priority of the exact local identity/rank result relative to Dey et al. cannot be settled without the cited full-text passages. No claim that earlier papers omit these properties is added. |
| Third-round affinity statement | Name the unfinalized word-7 map in the abstract and conclusion. Distinguish its nonzero derivative witnesses from the persistent 512-bit spectral structure of the standard additive output. |
| Local algebraic premise | Make explicit why the inputs to the second word-7 update remain independent of the initial second nonce word. This clarifies the existing derivation without changing its rank or mean-response identities. |
| Sign-flip inference | State the zero-mean null, the absolute whole-key mean statistic, and the stronger sign-invariance assumption required for exact calibration. Zero mean alone does not imply that condition. Preserve all archived values and separate fixed test families. |
| Spectrum normalization and L1 | Specify power averaging over bases, AC normalization per key/mask, averaging over masks and keys, and only then the L1 distance. These distances compare cipher spectra, not reference-subtracted spectra. |
| Actual spectra | Replace the old scalar-prediction top panels with observed/M0/M1 mean AC spectra. Retain the two round-transition panels. The new plot uses saved data and predictions, with a new source/figure manifest; earlier figure files remain unchanged. |
| Segment aggregation | Explain that adding adjacent HW values and decimating changes the observed trajectory; at fixed output length W the physical DFT spacing remains 1/W. |
| Model simulation error | Report the existing M1 Salsa20 128-bit entropy-gap MCSE of 0.00038 bits alongside the observed-minus-predicted error of 0.00667 bits, separately from evaluation-key uncertainty. |
| Data availability | Identify `iv_diffusion_research_review_v0.20.0.zip`, version 0.20.0, and its included `SHA256SUMS.json` manifest. This archive is prepared for reviewers; it has not been publicly deposited or submitted. A public URL/DOI is not invented. |

No new detector-superiority comparison, attack, additional key cohort, or
